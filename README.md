# 소방설비기사(전기) 실기 기출문제 앱

개인용 학습 웹앱입니다. 문제를 화면에서 풀고, 정답을 확인한 뒤 스스로 O/X로 채점하면
기록이 브라우저(localStorage)에 남아 "틀린 문제만 다시 풀기"가 가능합니다.

## 사용 방법 (내 컴퓨터에서 바로 열기)
`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다.
(단, 일부 브라우저는 `file://` 로 열면 fetch가 막힐 수 있어 아래 GitHub Pages 방식을 추천합니다.)

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만듭니다 (예: `fire-exam-app`).
2. 이 폴더 안의 파일 전체(`index.html`, `style.css`, `app.js`, `data/`, `images/`)를
   저장소에 업로드(커밋)합니다.
3. 저장소의 **Settings → Pages** 로 이동합니다.
4. **Branch**를 `main` (또는 사용 중인 브랜치), 폴더는 `/ (root)`로 설정 후 저장합니다.
5. 잠시 후 `https://<본인아이디>.github.io/fire-exam-app/` 주소로 접속하면 앱이 열립니다.
6. 아이폰/아이패드 Safari에서 이 주소를 열고 **공유 → 홈 화면에 추가**를 하면
   아이콘을 눌러 앱처럼 바로 실행할 수 있습니다.

## 카테고리 구조
상단에 "카테고리" 드롭다운이 있고, 그 아래 "회차"(연도) 드롭다운이 있습니다.
카테고리 목록은 `data/categories.json`에서 관리합니다.

```json
[
  { "id": "gicho", "name": "실기 기출문제", "yearsFile": "years.json", "fileTemplate": "{year}.json" },
  { "id": "domyeon", "name": "도면 및 가닥수", "yearsFile": "domyeon-years.json", "fileTemplate": "domyeon-{year}.json" }
]
```

- `yearsFile`: 그 카테고리에 어떤 연도들이 있는지 적힌 파일 (예: `["2025","2024"]`)
- `fileTemplate`: 실제 문제 데이터 파일 이름 규칙. `{year}` 자리에 연도가 들어갑니다.

새 카테고리를 추가하고 싶으면 `categories.json`에 항목을 하나 더 추가하고,
그에 맞는 `yearsFile`과 문제 데이터 파일들을 만들면 됩니다.

## "실기 기출문제" 카테고리에 다음 연도 추가하는 방법
1. `data/2024.json` 처럼 연도별 파일을 새로 만듭니다. (구조는 `data/2025.json` 참고)
2. `data/years.json` 파일에 연도를 추가합니다.
   ```json
   ["2025", "2024"]
   ```
3. 그림이 있는 문제는 `images/` 폴더에 이미지를 추가하고,
   JSON에서 `"image": "images/파일명.png"` 형태로 지정합니다.
   연도가 늘어나면 파일명이 겹칠 수 있으니 **`연도_q문항번호.png`** 형식을 사용하세요.
   (예: 2024년 5번 문제 그림 → `images/2024_q05.png`)
4. 커밋 후 GitHub Pages에 반영되면 상단 "회차" 선택에서 새 연도를 고를 수 있습니다.

## "도면 및 가닥수" 카테고리에 문제 추가하는 방법
이 카테고리는 문제 자체가 도면(그림)이라 이미지로 보여주고, 정답은 텍스트로 입력합니다.
1. 문제 도면 사진과 정답 사진을 준비합니다 (예: `do_q001`, `do_a001`처럼 구분해서 촬영).
2. 채팅에 두 사진을 업로드하면, 문제 이미지는 `images/domyeon_연도_q001.png` 같은 이름으로
   정리해서 저장하고, 정답 사진은 내용을 읽어서 텍스트로 옮겨 `data/domyeon-연도.json`에
   추가해 드립니다.
3. 그 연도가 `data/domyeon-years.json`에 없으면 추가합니다.
   ```json
   ["2025"]
   ```
4. HEIC(아이폰 기본 사진 포맷)으로 찍어서 그대로 올려주셔도 변환해서 처리합니다.

## 문제 데이터 구조 (`data/2025.json`)
```json
{
  "year": 2025,
  "exam": "소방설비기사(전기) 실기",
  "questions": [
    {
      "id": 1,
      "text": "문제 본문 (여러 줄은 \\n 으로 줄바꿈)",
      "image": "images/q05.png",   // 그림 문제일 때만 있음, 없으면 생략 가능
      "parts": [
        { "label": "①", "answer": "모범 답안" }
      ]
    }
  ]
}
```

## 모드 설명
- **전체 순서대로**: 문제 번호 순서대로 풀기
- **무작위**: 매번 랜덤 순서로 섞어서 풀기
- **틀린 문제만**: 이전에 "X 틀림"으로 채점한 문제만 모아서 다시 풀기

## 인쇄해서 풀고 싶을 때
`index.html`을 브라우저로 연 상태에서 Ctrl+P(또는 Cmd+P)로 인쇄하면
현재 보고 있는 문제 화면을 그대로 인쇄할 수 있습니다. 전체 문제를 한 번에
인쇄하고 싶다면 말씀해 주시면 인쇄용 PDF도 별도로 만들어 드릴 수 있습니다.

직접 입력한 것입니다. 개인 학습 외의 용도로 배포하지 않도록 주의하세요.
